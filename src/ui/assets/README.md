# Adobe Spectrum workflow icons

Os SVGs deste diretório foram extraídos de
`@spectrum-web-components/icons-workflow` versão `1.12.2`, publicado pela
Adobe sob a licença Apache-2.0:

- `text-bold.svg`: `TextBoldIcon`;
- `text-italic.svg`: `TextItalicIcon`;
- `text-underline.svg`: `TextUnderlineIcon`;
- `text-bulleted.svg`: `TextBulletedIcon`;
- `text-numbered.svg`: `TextNumberedIcon`.
- `chevron-down.svg`: `ChevronDownIcon`;
- `chevron-right.svg`: `ChevronRightIcon`;
- `document.svg`: `DocumentIcon`;
- `file-code.svg`: `FileCodeIcon`;
- `folder.svg`: `FolderIcon`;
- `folder-open.svg`: `FolderOpenIcon`;
- `project.svg`: `BriefcaseIcon`, usado para identificar a raiz do projeto.
- `file-add.svg`: `FileAddIcon`, usado para criar um documento Typst;
- `folder-add.svg`: `FolderAddIcon`, usado para criar uma pasta;
- `refresh.svg`: `RefreshIcon`, usado para atualizar a árvore do projeto;
- `preview.svg`: `PreviewIcon`, usado para identificar o documento exibido no Preview.

O SVG de interface foi extraído de
`@spectrum-web-components/icons-ui` versão `1.12.2`, sob a mesma licença:

- `cross-100.svg`: `Cross100Icon`, usado para fechar abas;
- `checkmark-100.svg`: `Checkmark100Icon`, usado em itens selecionados de menus.

As geometrias e o `viewBox` oficiais foram preservados. A moldura de cada SVG
foi reduzida aos atributos necessários para renderização interna no Iced; os
nomes acessíveis são fornecidos pelos botões e seus tooltips.

Fonte: <https://www.npmjs.com/package/@spectrum-web-components/icons-workflow/v/1.12.2>
